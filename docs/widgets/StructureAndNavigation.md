# Structure and Navigation

These widgets help organize the high-level layout of an application.

## Toolbar
A container for common actions, usually placed at the top or bottom of a window.
*   Uses `ToolbarButton` for a consistent look.

## Sidebar
A vertical navigation area, often used to switch between main sections or folders.
*   **`SidebarItem`**: Individual navigation entries.

## Panel and VPanel
Simple containers with themed backgrounds. `Panel` is horizontal and `VPanel` is vertical. They are used to group widgets visually.

## Statusbar
A thin bar at the bottom of the window to display informational messages.

## SearchBox
A specialized `TextBox` with a search icon and a clear button, optimized for filtering content.
