# Advanced Views

Horizon provides complex widgets for displaying and interacting with structured data.

## TableView
Displays data in a grid of rows and columns.
*   **`TableColumn`**: Defines header text and width.
*   **`TableRow`**: Represents a single record.
*   Supports sorting and selection.

## TreeView
Displays hierarchical data with expandable and collapsible nodes.
*   **`TreeViewItem`**: A node in the tree that can contain children.

## IconView and GroupedIconsView
Used for file browsing or application launchers.
*   Renders items as icons with labels.
*   Supports grid layout and drag-and-drop.
*   `GroupedIconsView` adds support for categorizing items into sections.

## CoverFlow
A 3D-like carousel for browsing images or cards with a focus on the central item.
